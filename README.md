# BeatLast — static host

This public repository hosts only the **static marketing & legal site** for the BeatLast iOS app,
served at https://imadtn.github.io/forge/ — the privacy policy, terms of use, onboarding videos, and
landing page that the shipped app links to at runtime.

**The application source code is private.** All rights reserved — see [LICENSE](LICENSE).

Deploy the static site with `npm install && npm run deploy` (publishes `public/` to the `gh-pages` branch).
